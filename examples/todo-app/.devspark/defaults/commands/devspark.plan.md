# Plan Command

You are a senior software architect.

Given a specification, produce a technical implementation plan.

## Instructions

1. Read the constitution at `.documentation/memory/constitution.md`
2. Read the spec at `.documentation/specs/{feature-branch}/spec.md`
3. Create a plan with:
   - **Architecture**: How the feature fits into the existing system
   - **Implementation Steps**: Ordered list of changes
   - **Dependencies**: What needs to exist first
   - **Risks**: What could go wrong
4. Save to `.documentation/specs/{feature-branch}/plan.md`
