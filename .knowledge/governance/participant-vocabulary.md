# Participant Vocabulary

Use **agent** for an AI runtime or configured coding assistant. Use **participant** for a human team
member, reviewer, approver, or contributor. This distinction keeps runtime configuration separate
from responsibility and approval records.

An **accountable participant** is the named human or role authorized to establish standing assurance
expectations and ratify material risk decisions. A **ratifier** acts within that delegated authority;
silence never supplies ratification. Routine work inside established expectations does not require
fresh ratification merely because an agent assisted it.

**Independent assurance** means a cross-check with meaningful separation from the implementing
agent's claims. Another model using separate context can independently challenge reasoning;
deterministic tests, separate execution environments, devices, and attributable human observation
provide different kinds of evidence. Do not treat a separate model's agreement as a passing test
or as independent human approval.
