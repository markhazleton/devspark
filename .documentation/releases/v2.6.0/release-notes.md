## Highlights

DevSpark now treats Antigravity, DeepMind's built-in agentic IDE assistant, as a first-class agent: it is registered in `agents-registry.json`, gets its own quickstart guide and integration doc, and is listed everywhere other agents are (README, docs TOC, `CLAUDE.md`, CLI help text). DevSpark now supports 18 AI agents.

This release also improves `devspark upgrade` agent auto-detection so Antigravity and Gemini CLI — which share the `.gemini/` folder — are distinguished correctly instead of falling through to generic detection, and clarifies the `--allow-dirty` CLI help text. A documentation harvest pass archived 10 stale audit/harvest/repo-story/PR-review artifacts beyond their retention window.

No code-level features required a spec or ADR this cycle — Antigravity integration follows the existing agent-extensibility pattern documented in `CLAUDE.md`, so it shipped as direct commits rather than a full spec lifecycle.

### Make Bold Solutions and Make Bold Spark Brand Assets

Added brand guides, logo/asset packages, and contact card metadata for Make Bold Solutions and Make Bold Spark under `.documentation/branding/`.
