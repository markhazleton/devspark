## Highlights

v2.4.0 introduces **Agent Skills** — DevSpark's first portable capability surface. Where
slash-commands own DevSpark-specific lifecycle concerns (branch creation, multi-app scoping,
gate enforcement), Agent Skills own portable reasoning that runs in any skills-compatible
client without a DevSpark installation.

The pilot ship is `write-spec`, a standalone skill for spec-drafting that complies with the
open Agent Skills specification (agentskills.io). The `/devspark.specify` command is
refactored as a thin wrapper that delegates to the skill via a documented adapter contract,
preserving all existing user-facing behavior.

This release also hardens the CI pipeline (tests now gate releases) and refactors two
large source modules below the quality threshold.

## New Features

### Agent Skills Surface (`templates/skills/`)

A new top-level directory parallel to `templates/commands/`. Each subdirectory is a portable
Agent Skill — a `SKILL.md` entry point plus optional context-gathering scripts and references
that run in any skills-compatible client without DevSpark installed.

**Spec**: [View archived spec](specs/003-add-first-skill/spec.md)

### `write-spec` Skill

The pilot Agent Skill (`templates/skills/write-spec/SKILL.md`) packages spec-drafting as a
portable capability. Bundles dual-parity context-gathering scripts (PowerShell + Bash) for
constitution loading and prior-spec summary. Any skills-compatible client can load this folder
and produce a draft `spec.md` with zero DevSpark-specific configuration.

### Adapter Contract

`templates/skills/ADAPTER-contract.md` defines the boundary between commands and skills:
discovery (path resolution), input mapping, output mapping, responsibility split, and
backward-compatibility rules.

### `devspark skills` CLI

New subcommand group: `devspark skills list` enumerates skills in `templates/skills/`, and
`devspark skills validate [path]` validates all skills or a specific path against the skill
validation contract. Returns non-zero on any failure.

### First-Class Codex Quickstart

`quickstart/devspark_quickstart_codex.md` added. Codex is now surfaced alongside Claude Code
and GitHub Copilot in the recovery guidance for missing release assets.

## Deferred Features

None — all `003-add-first-skill` user stories delivered.

The following areas are explicitly out of scope and remain deferred:

- Conversion of any command other than `/devspark.specify` to a skill.
- Publishing skills to an external registry (agentskills.io showcase, community index).
- Auto-generating skills from all 28 commands.

## Upgrade Guide

No breaking changes. Consumer projects upgrading from v2.3.0 receive:

1. The `templates/skills/` directory (new, additive).
2. The refactored `templates/commands/specify.md` (user-observable behavior unchanged).
3. Two new CLI subcommands: `devspark skills list` and `devspark skills validate`.

Run `devspark upgrade` to apply the new template package.
