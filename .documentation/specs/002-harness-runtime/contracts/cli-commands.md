# Contract: CLI Commands

This file is a sample repair-prompt used by `sample.harness.yaml` to
demonstrate the `repairPrompt` and `human_gate` features of the harness
runtime.

## Expected CLI Commands

- `devspark harness run <file>` — execute a harness workflow
- `devspark harness run <file> --hands-off` — run without human gates
- `devspark harness run <file> --adapter <name>` — override the adapter
