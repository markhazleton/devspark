### Optional Improvements

- [ ] **L-01** [src/devspark_cli/runner/telemetry.py](src/devspark_cli/runner/telemetry.py#L107-L109) — Timestamp validation `ts.endswith("Z") or "+" in ts or "-" in ts[10:]` is a heuristic that lets through strings like `2026-04-18T00:00:00-bogus`. The subsequent `fromisoformat` catches them, so the heuristic is dead-weight. Drop the heuristic and rely on `fromisoformat`.
- [ ] **L-02** [pyproject.toml](pyproject.toml#L28-L30) — Wheel `force-include` only ships `agents-registry.json`. New `templates/aliases/*.yaml` and `templates/workflows/*.yaml` aren't in the wheel. Release zip path (`.github/workflows/scripts/create-release-packages.sh:336`) does cover them via `.devspark/templates/`, so users on the install/upgrade path are fine — but `pip install devspark-cli` users will only have aliases/workflows on the resolution chain if they happen to also have `.devspark/templates/`. Optional hardening: include them in the wheel too, or document the requirement in `quickstart/`.
- [ ] **L-03** [.github/agents/copilot-instructions.md](.github/agents/copilot-instructions.md) — Pre-existing markdownlint debt (MD025 multiple H1 line 32, MD012 double blank line 656) — touched but not introduced by this PR. Out of scope for merge but worth a follow-up.

### Constitution Improvements (Non-blocking — feed into `/devspark.evolve-constitution`)

- [ ] **CON-01** §III Ownership Boundary — The constitution says "Install and upgrade flows must never add, remove, or modify files under any `.documentation/` directory." This PR introduces runtime telemetry (`TelemetryWriter`) and pause-state writers (`write_pause_state`) whose **default path is `.documentation/telemetry/…`**. Runtime writes are not "install/upgrade" so technically compliant, and `.gitignore` keeps them out of git. But the principle is silent on whether application/runtime tooling may write to `.documentation/`. Recommend amending §III to explicitly carve out: *"Runtime tooling MAY write under `.documentation/<gitignored-subtree>/` provided the path is gitignored and the tool exposes an environment variable override."*

- **Hardened issue adapter**: [src/devspark_cli/issues.py](src/devspark_cli/issues.py#L122-L128) hardcodes `argv = ["gh", "api", ENDPOINT, "-X", "POST", "--input", "-"]` and pipes the JSON payload via stdin. Repo is locked to `markhazleton/devspark`. Classification is whitelisted via a fixed dict. Adversarial test exists (per PR description).

- **Strict telemetry envelope**: 4 KB event cap, 1 KB context cap, 500-char error cap, ISO-8601 enforcement, schema-versioned. Prevents runaway telemetry from bloating the JSONL store.
- **Spec → tasks → gates discipline**: `spec.md` Status=Complete, `tasks.md` 78/78, `gates/analyze.md` and `gates/critic.md` both PASS — this is exactly the lifecycle the constitution demands.
